# AIMoG Apex — Clarity Evaluation Demo Overview

This demo is a narrative‑first, public‑safe illustration of how AIMoG Apex approaches clarity through disciplined reasoning.  
It mirrors the conceptual self‑check loop described in the README and demonstrates it in action.

---

## **What This Demo Shows**

AIMoG Apex does not rely on a single attempt.  
It evaluates its own output, checks for clarity and structure, and refines when needed.

This demo illustrates:

- draft generation  
- self‑evaluation  
- refinement (when necessary)  
- final output  

All using a lightweight, Phase‑9‑aligned model.

---

## **How to Run the Demo**

From the `clarity-evaluation-demo` directory:

```
python run_demo.py
```

You will be guided through:

1. Draft generation  
2. Evaluation  
3. Optional refinement  
4. Final output  

The script prints each step with composure.
