## **Refined Response**
**1. Core framing**  
Recursion is a problem‑solving pattern where a process resolves a task by applying the same process to a smaller instance of that task.

**2. Systems‑thinking alignment**  
It resembles a system that delegates work to a reduced version of itself until the task reaches a stable stopping condition.

**3. Essential components**  
- a task that can be decomposed  
- a smaller, structurally similar sub‑task  
- a termination condition to prevent infinite delegation  

**4. Concrete illustration**  
Imagine a workflow that processes a stack of documents:  
- handle the top document  
- delegate the remaining stack to the same workflow  
- stop when no documents remain  

**5. Next step**
